# Test cases of the hmac package, kept as data, in gotgan's case format.
#
# One case per line: ARGS|STDIN|STDOUT. ARGS is the command line of tests/driver.bmb:
# the operation (mac, verify_slice or verify_truncated_left), the key length and the
# message length. STDIN is the key, then the message, then (for the verify operations)
# the tag to verify, written byte for byte as \xHH. STDOUT is the tag as lowercase hex
# for mac, and ok or error for the verify operations. Lines that start with # are
# comments.
#
# RFC 4231 section 4, test cases 1 to 7 (HMAC-SHA-256), as the original crate keeps
# them in tests/data/hmac_sha256_rfc4231.blb (decoded with the blobby crate).
# Test case 5 is specified truncated to 128 bits: the file holds the whole tag, and
# the RFC's truncated value is its first 16 bytes, checked with verify_truncated_left.
